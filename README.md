## Описание проекта
Программа визуализирует двумерную проекцию движения точки в соответствии с системой дифференциальных уравнений Лоренца (σ=10, r=28, b=8/3) методом Рунге-Кутты 4-го порядка. Реализовано интерактивное управление параметрами через слайдеры и переключение плоскостей проекции.

## Функциональные возможности
### Основной функционал
- 🦋 Пошаговая отрисовка фазового портрета аттрактора Лоренца
- 🧮 Интегрирование системы ОДУ методом Рунге-Кутты 4-го порядка (RK4)
- 🌈 Градиентная раскраска траектории движения точки

### Дополнительный функционал
- 🎚️ Интерактивные слайдеры для изменения параметров σ, r и b в реальном времени
- 🔄 Переключение плоскостей проекции (XZ, XY, YZ)
- ⏯️ Управление паузой (Space) и сбросом траектории (R)

## Требования к системе
- **Python:** 3.9 или выше
- **ОС:** Windows / macOS / Linux
- **Библиотеки:** 	kinter (встроенная)

## Установка и запуск
### 1. Клонирование репозитория
`ash
git clone [https://github.com/Loguzus/lorenz-attractor-animation-3.1.git](https://github.com/Loguzus/lorenz-attractor-animation-3.1.git)
cd lorenz-attractor-animation-3.1
`
### 2. Создание и активация виртуального окружения
`ash
py -m venv venv
venv\Scripts\activate
`
### 3. Установка зависимостей
`ash
pip install -r requirements.txt
`
### 4. Запуск программы
`ash
py main.py
`
### 5. Управление
- **Space** — пауза / продолжение анимации
- **R** — сброс траектории в начальную точку
- **Слайдеры** — регулировка параметров σ, r, b
