## Описание проекта
Программа визуализирует двумерную проекцию движения точки в соответствии с системой дифференциальных уравнений Лоренца ($\sigma=10$, $r=28$, $b=8/3$) с начальным положением $(0, 0, 0.1)$. Реализовано интерактивное управление параметрами системы через слайдеры, смена плоскостей проекции (XZ, XY, YZ) и пауза.

## Требования и запуск
1. Клонируйте репозиторий: `git clone <ссылка>`
2. Создайте окружение: `python -m venv venv`
3. Активируйте: `venv\Scripts\activate`
4. Запустите: `python main.py`
